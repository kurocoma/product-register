## 1. 製品情報・商品仕様の自動入力機能 (Codex リサーチ)

**起票日:** 2026-05-13 (商品登録アプリ 楽天検証時に要望)

### 概要

統一入力 CSV の作成時、 商品名や JAN コードから **製品情報・商品仕様を Codex CLI 経由でリサーチして自動入力** する機能。

### 想定フロー

```
商品名 / JAN コード / 仕入先 URL
       ↓ Codex CLI で Web リサーチ
製品情報 (原材料 / 内容量 / 賞味期限 / アレルギー / 製造者 / 栄養成分)
       ↓ ProductInput に流し込み
description_pc / description_4 / attribute_item_1〜5 / 商品属性 etc.
```

### 検討事項

- Codex CLI は同期実行で**長時間ブロック**する → バックグラウンド処理 or バッチで前夜実行
- ChatGPT Pro 利用枠を消費 (商品 1 件 = 通常応答の 3〜5 倍)
- Web スクレイピングが必要なら別途 Playwright が必要
- 結果の **検証・編集 UI** が必須 (LLM 出力をそのまま信用しない)
- 既存の Claude プロジェクトで商品説明 HTML 生成は運用中
  → そちらと統合 or 別 Web リサーチサブタスクとして分離

### スコープ判断

**重い機能** のため Phase 1 (CSV 出力 CLI) には含めず、 Phase 2 (WebUI + API 自動登録) と
同時または後に検討。 もしくは **独立した CLI ツール**として切り出す案もある。
