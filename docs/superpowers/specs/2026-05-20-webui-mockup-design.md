## 1. 確定方針

| 項目 | 内容 |
|---|---|
| **技術スタック** | Next.js (App Router) + Supabase + TypeScript |
| **CSV 変換ロジック** | Python から TypeScript に**全面再実装** |
| **認証** | Supabase Auth (Email + Magic Link) |
| **データ永続化** | Supabase (商品データ・ユーザー紐付き) |
| **データ管理単位** | 商品一覧 + 1 商品ごと詳細編集 |
| **プレビュー方式** | 楽天/Yahoo/Shopify の**本番ストア風 UI をクローン** (NE はプレビュー対象外) |
| **画像** | アップロード UI モック化、実装は Phase 2 以降 |
| **CSV ダウンロード** | 1 商品ごと、各モール用 (4 ファイル) + 一括ダウンロード画面 |
| **自動保存** | 入力変更時 debounce 800ms で Supabase に upsert |
| **手動保存** | ヘッダー右に「保存」ボタンも併設 (自動保存と併用) |
| **アコーディオン** | 複数セクション同時展開許容 (1 つに制限しない) |
| **テンプレート機能** | 雛形テンプレートを保存し新規商品作成時に再利用 |

#### 左ペイン: アコーディオン式フォーム (7 セクション)

| # | セクション | フィールド数 | 主な項目 |
|---|---|---|---|
| 1 | 基本情報 | 10 | ne_code, jan_code, 商品名, 価格, 税率 |
| 2 | 配送・カテゴリ | 6 | shipping_type, image_count, mall_category_id |
| 3 | 商品説明 | 10 | catch_copy_pc, description_pc, description_sp |
| 4 | Yahoo grouping | 5 | yahoo_category_id, unit, yahoo_grouping_enabled |
| 5 | バリエーション | 6 | option_item_name, variation_name |
| 6 | 画像 URL | 20 | image_url_1〜20 (+ 各列にサムネイル表示) |
| 7 | 商品属性 | 15 | attribute_item/value/unit × 5 |

#### 右ペイン: 3 タブ + CSV ダウンロード

- **タブ**: 楽天 / Yahoo / Shopify (NE はプレビュー対象外、CSV のみ出力)
- **プレビュー**: 各モール本番ストア風 UI クローン
  - 楽天: 商品画像メインビュー + 本数セレクタ + 価格 + 説明 (imgList 展開)
  - Yahoo: 商品画像 + 数量セレクタ (grouping) + caption HTML
  - Shopify: 商品画像 + バリアントセレクタ + マーケット (日本/国際) + Body HTML
- **自動更新**: 左ペインの入力編集が即時プレビューに反映 (React state)
- **CSV ダウンロード**: ボタンクリックで該当モールの CSV を生成・ダウンロード

#### 自動保存

入力変更時に **debounce 800ms** で Supabase に upsert (ヘッダー右端に「自動保存済み HH:MM」表示)。

## 4. データモデル (Supabase テーブル)

### 4.1 主要テーブル

```sql
-- ユーザー: Supabase Auth が管理 (auth.users)

-- 商品マスタ
CREATE TABLE products (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users NOT NULL,
  ne_code text NOT NULL,
  jan_code text NOT NULL,
  maker_code text NOT NULL,
  product_type text NOT NULL,
  quantity int NOT NULL,
  product_name text NOT NULL,
  display_name text NOT NULL,
  tax_rate int NOT NULL,
  selling_price int NOT NULL,
  -- ... (71 列分のフィールド、 JSON 列で柔軟性を持たせる選択肢もあり)
  attributes jsonb NOT NULL DEFAULT '{}'::jsonb,
  yahoo_grouping_enabled bool NOT NULL DEFAULT false,
  unit text DEFAULT '',
  yahoo_variation_title text DEFAULT '',
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (user_id, ne_code)
);

-- 店舗設定 (1 ユーザー 1 行)
CREATE TABLE settings (
  user_id uuid PRIMARY KEY REFERENCES auth.users,
  rakuten_store_id text,
  rakuten_cabinet_url_base text,
  yahoo_store_id text,
  shopify_store_id text,
  updated_at timestamptz NOT NULL DEFAULT now()
);

-- メーカーコードマスタ (1 ユーザー N 行)
CREATE TABLE maker_codes (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users NOT NULL,
  maker_code text NOT NULL,
  maker_name text NOT NULL,
  UNIQUE (user_id, maker_code)
);

-- 作業履歴
CREATE TABLE history (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users NOT NULL,
  action text NOT NULL,  -- 'create' | 'edit' | 'csv_export' | 'delete'
  product_id uuid REFERENCES products,
  detail jsonb,
  created_at timestamptz NOT NULL DEFAULT now()
);

-- 商品テンプレート (新)
CREATE TABLE product_templates (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users NOT NULL,
  name text NOT NULL,           -- 例: "お酒 - 単品 (古酒)"
  category text,                -- 例: "沖縄のお酒"
  template_data jsonb NOT NULL, -- 71 列のうち雛形にしたい値のサブセット
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);
```

### 4.2 RLS (Row Level Security) ポリシー

```sql
-- 各ユーザーは自分のデータのみ参照可
ALTER TABLE products ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage own products"
  ON products FOR ALL USING (auth.uid() = user_id);
```

## 6. データフロー

```
ユーザー編集
  ↓
ProductForm の React state 更新
  ↓
useEffect (debounce 800ms)
  ↓
Supabase upsert
  ↓
ヘッダー「✓ 自動保存済み HH:MM」表示

ユーザー編集
  ↓
ProductForm の React state 更新 (同期的)
  ↓
PreviewTabs / RakutenPreview / YahooPreview / ShopifyPreview に props 経由で反映
  ↓
即時プレビュー更新

CSV ダウンロードボタンクリック
  ↓
/api/csv/{mall}/{id} に GET
  ↓
サーバー側で converters/{mall}.ts を呼んで CSV 文字列生成
  ↓
適切な encoding (楽天/Yahoo: cp932, NE: utf-8, Shopify: utf-8-sig) で blob
  ↓
ブラウザがダウンロード
```
